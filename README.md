# 金融衍生工具实践 1：期货市场运作机制

北京师范大学 2026 秋季学期。围绕中国银行「原油宝」穿仓事件，回答三个问题：原油宝与原油期货的区别、WTI 2005 价格跌为负值的原因、如何避免穿仓再次发生。报告正文是 `报告.qmd`。

仓库：<https://github.com/aylmerwawa/derivatives-lab1-crude-oil-treasure>

## 文件

| 文件 | 内容 |
|------|------|
| `报告.qmd` | 报告源文件 |
| `作图.py` | 三张图的脚本：交易角色、账户权益与价格、原油宝关闭与结算价的时间差 |
| `结果/` | 脚本输出的图（`fig-01` 到 `fig-03`） |

## 材料

案例原文（中国管理案例共享中心案例库，有版权）和题面截图不在仓库里。报告里的数据都来自该案例和课程课件，页码已在正文中标注。

## 运行

conda 环境 `ml`（matplotlib）。

```bash
python 作图.py
```

图写入 `结果/`。生成 PDF：

```bash
quarto render 报告.qmd --to pdf
```
